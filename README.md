Software engineer in Hanoi. I build Go backends, maintain a custom Chromium build, and write tooling for AI coding agents.

### Work

**Sourcing & fulfillment platform.** 22 Go services over Connect RPC and NATS JetStream, one Postgres per service, events through a transactional outbox. Closed source; I wrote up the patterns in [event-driven-go-notes](https://github.com/phquand2000/event-driven-go-notes).

**Custom Chromium build.** About 66 patches across canvas, audio, WebGL, fonts, TLS and HTTP/2. Closed source; what it touches is mapped in [browser-fingerprint-surfaces](https://github.com/phquand2000/browser-fingerprint-surfaces).

**Messaging ops desktop.** A Wails v3 app (Go and React) that keeps many messaging accounts in one window, read-only, plus the licensing server behind it.

**Paseo Crew.** My fork of Seatworks, a plugin that runs a small team of coding agents on one project.

**[AE AI Assistant](https://github.com/phquand2000/adobe_effects_ext).** After Effects extension that puts 158 actions under natural-language control.

**[n8n Premium](https://github.com/phquand2000/n8n_folk_premium).** n8n fork with an AI workflow builder.
